# 2026_ECGI_Data_Challenge
## Background
During the 2026 ECGI summit in Valencia spain (link), the winner of the 2026 ECGI data challenge will be announced. This repo contains the code for metrics used to evaluate submissions. Each dataset has a custom goal or target metric. These metrics are normalized into a final score across all datasets.
